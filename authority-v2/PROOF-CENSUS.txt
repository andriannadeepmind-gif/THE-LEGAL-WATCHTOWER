# ΔΙΟΡΘΩΣΗ ΣΤΗΝ ΑΙΤΙΑ — ΕΝΑΣ ΚΑΤΑΛΟΓΟΣ ΕΙΣΟΔΩΝ:
#   · ΟΛΕΣ οι αποδείξεις ζουν ΑΠΟΚΛΕΙΣΤΙΚΑ στο authority-v2/proofs/.
#   · Ο runner απαριθμεί ΑΝΑΔΡΟΜΙΚΑ ΚΑΘΕ regular file κάτω από το authority-v2/
#     (ΟΧΙ globs) και απαιτεί:
#       - κάθε αρχείο ΜΕΣΑ στο proofs/ να είναι εγγεγραμμένο εδώ, και αντίστροφα
#       - ΚΑΝΕΝΑ εκτελέσιμο απόδειξης ΕΚΤΟΣ του proofs/ — εκτός αν δηλώνεται
#         ρητά εδώ ως `tool-*` (μη-απόδειξη) με λόγο
#   · Αντίπαλος: authority-v2/proofs/proof-census-adversarial-test.py, που
#     φυτεύει authority-v2/other/forgotten-proof.py και απαιτεί ΚΟΚΚΙΝΟ.
#
# ΣΧΗΜΑ (κλειστό): <repo-relative-path>  <τροπος>  [ορίσματα...]
#   plain               - τρέχει χωρίς προνόμια
#   requires-sbcl       - απαιτεί τον παραγωγικό Lisp πυρήνα (διαφορικές έδρες)
#   requires-root       - απαιτεί root+CAP_SYS_ADMIN (mount/setpriv/unshare).
#                         Τοπικά χωρίς root => BLOCKED (ΠΟΤΕ pass). Στο CI με
#                         AUTHORITY_V2_REQUIRE_ALL=1 => ΣΦΑΛΜΑ.
#   tool-requires-root  - ΕΡΓΑΛΕΙΟ/ΠΡΟΕΤΟΙΜΑΣΙΑ, ΟΧΙ απόδειξη: τρέχει ΠΡΩΤΟ, δεν
#                         μετριέται, και επιτρέπεται να ζει ΕΚΤΟΣ του proofs/.
#   tool-declared       - ΕΡΓΑΛΕΙΟ που ΔΕΝ εκτελείται από τον runner· δηλώνεται
#                         ΜΟΝΟ για να επιτραπεί ρητά η ύπαρξή του εκτός proofs/.
# =============================================================================
