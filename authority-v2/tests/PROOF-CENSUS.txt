# ΕΥΡΗΜΑ ΔΗΜΙΟΥΡΓΟΥ (P1): «τίποτα δεν είναι συρματωμένο σε Docker/compose/CI».

# είναι ακριβώς αυτό που ο νόμος απαγορεύει — και η επόμενη απόδειξη που θα
# γραφτεί ΔΕΝ θα μπει ποτέ, σιωπηλά.
#
# ΕΔΩ: ΜΙΑ committed απογραφή. Ο εκτελεστής (run-authority-v2-proofs.sh)
# ΠΑΡΑΓΕΙ το inventory από το filesystem και το ΣΥΓΚΡΙΝΕΙ με αυτό το αρχείο.
#   · αρχείο στον δίσκο που ΛΕΙΠΕΙ από εδώ  ⇒ ΣΦΑΛΜΑ (ξεχασμένη απόδειξη)
#   · γραμμή εδώ χωρίς αρχείο στον δίσκο    ⇒ ΣΦΑΛΜΑ (νεκρή εγγραφή)
# Καμία απόδειξη δεν μπορεί να ξεχαστεί, και καμία εγγραφή δεν μπορεί να μείνει
# να δείχνει στο κενό.
#
# ΣΧΗΜΑ (κλειστό): <αρχείο>  <τρόπος>
#   plain          — τρέχει χωρίς προνόμια
#   requires-root  — απαιτεί root+CAP_SYS_ADMIN (mount/setpriv/unshare). Τοπικά
#                    χωρίς root ⇒ BLOCKED (ποτέ pass). ΣΤΟ CI ⇒ ΣΦΑΛΜΑ: εκεί ο
#                    root υπάρχει, άρα BLOCKED σημαίνει απώλεια δυνατότητας.
#   requires-sbcl  — απαιτεί τον παραγωγικό Lisp πυρήνα (διαφορικές έδρες)
