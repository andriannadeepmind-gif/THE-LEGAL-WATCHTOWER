# ΕΤΥΜΗΓΟΡΙΑ ΔΗΜΙΟΥΡΓΟΥ: «Το verify-capability-closure.sh ΔΕΝ περιλαμβάνεται:
# ο runner απογράφει μόνο συγκεκριμένα globs μέσα στο authority-v2/tests/.
# Επομένως ο ισχυρισμός “τρέχει όλες τις αποδείξεις” είναι ψευδής.» ΟΡΘΟ.
#
# ΔΙΟΡΘΩΣΗ ΣΤΗΝ ΑΙΤΙΑ: η απογραφή είναι ΠΛΕΟΝ ΣΕ ΕΠΙΠΕΔΟ ΑΠΟΘΕΤΗΡΙΟΥ, με
# repo-relative μονοπάτια, και το inventory παράγεται από globs που καλύπτουν
# ΟΛΟ το authority-v2/ (tests/, capability/, και τους verifiers της ρίζας του).
#   · αρχείο στον δίσκο που ΛΕΙΠΕΙ από εδώ  ⇒ ΣΦΑΛΜΑ (ξεχασμένη απόδειξη)
#   · γραμμή εδώ χωρίς αρχείο στον δίσκο    ⇒ ΣΦΑΛΜΑ (νεκρή εγγραφή/ορφανό)
#   · ίδιο μονοπάτι δύο φορές               ⇒ ΣΦΑΛΜΑ (διπλότυπο)
#   · άγνωστος τρόπος                       ⇒ ΣΦΑΛΜΑ (κλειστό σχήμα)
# Αντίπαλος: authority-v2/tests/proof-census-adversarial-test.py
#
# ΣΧΗΜΑ (κλειστό): <repo-relative-path>  <τρόπος>  [ορίσματα…]
#   plain               — τρέχει χωρίς προνόμια
#   requires-sbcl       — απαιτεί τον παραγωγικό Lisp πυρήνα (διαφορικές έδρες)
#   requires-root       — απαιτεί root+CAP_SYS_ADMIN (mount/setpriv/unshare).
#                         Τοπικά χωρίς root ⇒ BLOCKED (ΠΟΤΕ pass). Στο CI, με
#                         AUTHORITY_V2_REQUIRE_ALL=1 ⇒ ΣΦΑΛΜΑ: εκεί ο root
#                         υπάρχει, άρα BLOCKED σημαίνει απώλεια δυνατότητας.
#   setup-requires-root — ΠΡΟΕΤΟΙΜΑΣΙΑ (όχι απόδειξη): τρέχει ΠΡΩΤΗ, δεν
#                         μετριέται ως απόδειξη· η αποτυχία της μπλοκάρει τα
#                         requires-root.
# =============================================================================
