# ARC-AGI (Abstraction and Reasoning Corpus) — επίσημα έργα

Πηγή: François Chollet, **fchollet/ARC-AGI** (άδεια Apache-2.0).
Τα 400 έργα εκπαίδευσης (`train/`) και τα 400 αξιολόγησης (`eval/`) στο
επίσημο JSON format, ένα αρχείο ανά έργο: `{"train": [{"input": …, "output": …}…],
"test": [{"input": …, "output": …}…]}`.

Εκτέλεση με τον λύτη ρευστής επαγωγής (orchestrator.fluid — DSL + αναζήτηση
+ ΑΚΡΙΒΗΣ επαλήθευση, ποτέ εικασία):

    --arc-eval input/arc/train/
    --arc-eval input/arc/eval/

Τυπώνει ΩΜΟ σκορ: σωστά (κύτταρο-κύτταρο ακριβή) · τίμιες αρνήσεις (εκτός
τρέχοντος DSL, με δηλωμένο λόγο) · λάθη (συνεπή με την εκπαίδευση αλλά
λάθος στη δοκιμή). Η πληρότητα του λύτη πάνω στο εκάστοτε DSL φυλάσσεται
από την πύλη `--fluid-gate` (κρυφά προγράμματα ως ανεξάρτητος κριτής).
Το DSL μεγαλώνει κύμα-κύμα — κάθε κύμα μετριέται εδώ, πριν/μετά.

Όλα τα υπόλοιπα είναι ΤΙΜΙΕΣ αρνήσεις με δηλωμένο λόγο — ο λύτης δεν
απαντά ποτέ χωρίς πρόγραμμα που εξηγεί ΟΛΑ τα παραδείγματα ακριβώς.
«Λάθη» = προγράμματα συνεπή με όλη την εκπαίδευση που απέκλιναν στη
δοκιμή (διφορούμενα έργα για το τρέχον DSL) — τυπώνονται, δεν κρύβονται.
