# Νομολογία — πηγές αποφάσεων

Δομή: ένας υποφάκελος ανά δικαστήριο.

    input/decisions/
      areios-pagos/          Άρειος Πάγος
        ap_<έτος>_<αριθμός>.<μορφή>     π.χ. ap_2023_1234.html

## Ονοματολογία αρχείων

`<δικαστήριο>_<έτος>_<αριθμός απόφασης>.<html|pdf|docx|txt>`

- Ο αριθμός και το έτος είναι η ταυτότητα της απόφασης (ΑΠ 1234/2023) —
  μπαίνουν ΣΤΟ όνομα ώστε η ταυτότητα να μην εξαρτάται από το παρσάρισμα.
- Δεκτή όποια μορφή δίνει η πηγή (το areiospagos.gr συνήθως HTML)·
  ο decisions adapter ανιχνεύει τη μορφή, δεν την υποθέτει.

## Ροή

1. Κατέβασε την απόφαση από την επίσημη πηγή.
2. Ονόμασέ την κατά τη σύμβαση και βάλε τη στον φάκελο του δικαστηρίου.
3. `git add input/decisions && git commit && git push`
4. Ο decisions adapter την παρσάρει σε δομημένη μορφή (στοιχεία σύνθεσης,
   νομικές διατάξεις που εφαρμόζει, σκεπτικό, διατακτικό), δένει τις
   παραπομπές της (π.χ. «άρθρο 300 ΑΚ») στο citation graph των κωδίκων,
   και περνάει από τα ίδια gates (provenance, fingerprints, audit).
