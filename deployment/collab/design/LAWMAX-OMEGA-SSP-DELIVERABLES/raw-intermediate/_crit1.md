## P0-3 — The credulous-argumentation elimination is a false lemma, and it hides a genuinely missing DIM-01 family (unique-status semantics above grounded)

**Quoted text (DIM-01 elimination):** "Violates H5: preferred/stable semantics yield non-unique extensions (NP-hard, answer depends on search order), so the trusted decision is not a pure function of frozen inputs." **Inherited ceiling text (AX-01):** "Any 'stronger' semantics either loses uniqueness (breaks H5 replay) or decidability (breaks H3 fail-closed termination)."

So a feasible, H1–H8-conformant family — "unique-status-certified argumentation above grounded (ideal/eager, skeptical-preferred with certified enumeration)" — is absent from DIM-01, eliminated by an unsound lemma inherited from the ceiling.

**Correction:** Add the family to DIM-01. If it is to be eliminated, the honest ground is PER_DIMENSION_DOMINANCE via AX-17 (P-time grounded vs coNP-complete ideal — a strictly worse declared complexity class on the same workload) **plus** an argument that the extra acceptances carry no AX-01 rank gain — and that second half must be argued, because "defeater-sensitive-checked" is semantics-relative and a court asked about an even-cycle norm conflict gets `undefined` from grounded where ideal may decide. As frozen, the ceiling's "unique maximal semantics" claim must be weakened to "unique maximal *polynomial-time* semantics," and P-time is nowhere an H-invariant — the elimination is taste (a complexity preference) dressed as an H5 proof.
