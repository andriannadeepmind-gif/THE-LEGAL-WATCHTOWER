# Fresh Phase-2 independent review runbook

## Before launch

1. Verify the outer freeze bundle and both inner capsule hashes.
2. Run `verify_freeze.py` and `verify_freeze.mjs` inside the reviewer capsule.
   Both must exit 0 and report `FREEZE_STRUCTURE_VALID`.
3. The creator approves the immutable outer, blind and reviewer hashes in one
   external receipt. Approval changes no package byte.
4. Provision an eligible environment under `COORDINATOR-LAUNCH-POLICY.json`.
   The baseline-connected Claude Code project is ineligible.
5. Upload only `PHASE-2-BLIND-PRODUCER-INPUT.zip`. Do not upload or mention the
   reviewer capsule, B0 identity, Phase 1 or prior Phase-2 work.

## After producer termination

1. Record the producer ZIP byte length and SHA-256 before opening it.
2. Preserve the complete Code session and tool transcript. Do not resume the
   producer for remediation.
3. Start a distinct reviewer session. Give it the immutable reviewer capsule,
   the frozen producer ZIP and the retained producer transcript.
4. Apply the answer-neutral gates and negative controls. Structural checks do not
   replace semantic review.
5. Verify that all three mandatory commercial products are individually present,
   every observable mechanism capability is mapped, the all-axis matrix contains
   exactly 66 cells, and the producer has not used content quantity, averages,
   weights, compensation, equality or `UNKNOWN` as superiority evidence.
6. The first review may issue only:

   - `PHASE_2_CANDIDATE_ACCEPTED_FOR_PROOF_PIPELINE`, when every semantic and artifact gate passes, accompanied by the separate blindness label; or
   - `PHASE_2_BLOCKED`, with exact failed gates.

An isolation evidence gap changes the blindness label to `UNVERIFIED`; it does not
force another architecture-production run and cannot establish or refute the final
ceiling theorem.

No checker may be modified to certify that same output. A discovered checker defect
is preserved as a failed review epoch. Repairing the reviewer for future work does
not retroactively accept the current producer output; the defect must be evaluated
under an independently justified rule already entailed by the frozen public spec.

judging. Before any Phase-3 comparison, instantiate and hash the complete domain
grammar/envelope, objective order and bins, material-equivalence rule, hard-

`RED_TEAM_TERMINATION = UNIVERSAL_PROOF_ONLY`.

reproduced as `STRICTLY_BETTER` and every product capability surface is a proper
subset under universal trace/capability refinement. One equal, worse, unknown,
unmapped or content-confounded cell blocks commercial superiority.

After B0 is revealed, activate FOC-19 before any repository write. Complete the
semantic repository census and produce the immutable bidirectional crosswalk,

branch/worktree. T7 passes only when the resulting source, build and executable are
the exact proved E_star and no parallel authority or unlisted change exists.

technology, workload or proof counterexample changes the live status to
