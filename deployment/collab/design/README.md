# ΣΧΕΔΙΑΣΤΙΚΟ ΑΡΧΕΙΟ — WATCHTOWER / LAWMAX-Ω

Κατάθεση του σχεδιαστικού και αποδεικτικού σώματος που μέχρι τώρα ζούσε **εκτός
repository** και επομένως ήταν εφήμερο. Καμία γραμμή εδώ δεν είναι εκτελέσιμος
κώδικας παραγωγής· τίποτα δεν φορτώνεται από κανένα σύστημα ASDF.

**ΚΑΤΑΣΤΑΣΗ: σχέδιο υπό αντιπαλική δοκιμή. ΤΙΠΟΤΑ ΔΕΝ ΕΧΕΙ ΕΓΚΡΙΘΕΙ ΓΙΑ ΥΛΟΠΟΙΗΣΗ.**
Εντολή δημιουργού: πρώτα βρίσκεται η οροφή και αποδεικνύεται ότι δεν σπάει· μόνο
τότε γράφεται κώδικας.

## Ο ΚΑΝΟΝΑΣ ΤΟΥ ΑΡΧΕΙΟΥ

Δύο κατηγορίες, με διαφορετικό καθεστώς μεταβολής:

- **ΑΡΧΕΙΟ** — αποτελέσματα εκτέλεσης, σφραγισμένες προδηλώσεις, καταθέσεις κρίσης,
  υπερκερασμένες εκδόσεις, blind inputs. **ΔΕΝ ΤΡΟΠΟΠΟΙΟΥΝΤΑΙ ΠΟΤΕ.** Μια
  προδήλωση που αναθεωρείται μετά την επίθεση είναι άχρηστη· ένα blind input που
  τροποποιείται παύει να είναι blind.
- **ΣΧΕΔΙΟ** — αρχιτεκτονική στόχου, μετάβαση, στρατηγική. Μεταβάλλεται **ΜΟΝΟ με
  νέα έκδοση**, ποτέ με επεξεργασία της παλιάς.

### Οι δύο προσθήκες που χρωστά το v0.7 (από την υπόθεση ολότητας)

Η υπόθεση «όλα τα υπαρκτά δεδομένα υπάρχουν, και για τις δύο πλευρές» **δεν σπάει**
το v0.7 — ποτέ δεν υπέθεσε σπανιότητα. Επιβάλλει όμως δύο απαιτήσεις που λείπουν:

1. **Ολική διάταξη αυθεντίας** πάνω στην ολότητα (*υπαρκτό ≠ ισχύον*: πρωτόδικη ≠
   Ολομέλεια ΑΠ· ανατραπείσα ≠ ισχύουσα· obiter ≠ ratio). Ο γάντζος υπάρχει
   (`authority_class` / `admission_class`, I-17/I-13)· η διάταξη όχι.
2. **Σχετικότητα με απόδειξη** (*γιατί αυτές οι 5 αποφάσεις από τις 200.000*).
   Καμία σημασιολογία επιλογής στο v0.7.
