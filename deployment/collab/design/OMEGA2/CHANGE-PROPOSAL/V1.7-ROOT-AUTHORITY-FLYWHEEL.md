## Loop invariant
The output of step 12 (priorities) feeds step 1 (census coverage/freshness) as **proposals**, never as canonical
mutations — every loop-back re-enters steps 2–7 gates. This closes the flywheel: better representation → more
citations → more adoption → more feedback → better coverage/freshness → better representation. Citation primacy
is pursued only through superior representation/coverage/freshness/proofs/resolver/integration
(`:RA-I-2`), never through false certainty.
