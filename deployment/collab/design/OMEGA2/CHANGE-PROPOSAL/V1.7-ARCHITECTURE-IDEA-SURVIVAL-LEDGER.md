## 3. Allowed-with-condition (explicitly permitted, bounded)
- **Catala / other DSL** → replaceable adapter for a strictly mechanical subfield, ONLY if it passes the same
  Legal-IR conformance corpus (`RA-ADAPTER-COND`).
- **Grammar-constrained decoding** → optimization of an optional proposer; output re-enters the non-evaluating
  schema decoder + semantic admission.
- **Counterfactual simulations** → branch/overlay with scenario identity over the immutable bitemporal root,
  never inside canonical reality.
