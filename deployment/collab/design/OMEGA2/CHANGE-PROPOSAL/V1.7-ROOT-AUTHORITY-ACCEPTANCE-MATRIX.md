# V1.7 ROOT-AUTHORITY ACCEPTANCE MATRIX (CANDIDATE · NORMATIVE · design-only)

**Parent `f05f5514`.** `ROOT_AUTHORITY` is a **typed, measurable, revocable, expiring** state
(`RootAuthorityQualification/1` + `RootAuthorityState` state machine, `V1.7-SCHEMAS.sexp §9`), never a permanent
marketing label. The **state machine is fully internal** (audit-checked). Everything that legitimately depends on
the outside world is recorded here as a **finite external gate** —
`id → owner → required evidence → entry gate / deadline → failure state` (§19) — and **may not** stand in for an
unresolved architecture decision. Failure of any mandatory gate **downgrades or expires** the state
(`auto_downgrade_on_expiry`).

## 2. Rules
- **No gate covers an architecture decision.** Every gate above is genuinely external (numeric SLOs, named
  people, legal validation, live measurement, signed agreements). None hides an unresolved internal design.
- **Monotonic honesty.** A gate not yet met yields the honest failure state (UNKNOWN / DOWNGRADED / BLOCKED /
  RIGHTS_UNKNOWN), never a fabricated pass. Citation metrics never become legal-correctness claims (RA-K).
- **Expiry is real.** `QUALIFIED` carries an `expiry`; on expiry the state auto-downgrades (KW-13/25 lineage).
- **Current status (this pass):** ALL gates are `PENDING` (design-only; no measurement, no QSR, no mission).
  The state machine and thresholds are specified; the evidence is future work under explicit creator order.
