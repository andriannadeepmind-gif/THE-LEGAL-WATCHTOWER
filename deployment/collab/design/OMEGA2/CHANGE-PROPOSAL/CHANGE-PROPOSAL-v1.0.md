## TRACK 1 — «Η απουσία παραχωρεί» (έμπιστο μονοπάτι)

### Π4 · Default DENY + μητρώο εντολών που φέρει συνταγματική κλάση
**Έδρες:** `source/constitutional-gate.lisp:41` (default `(values t nil nil nil)`
= ALLOW), :43-45 (predicate error ⇒ fail-open)· `cli-util.lisp:46` (register-command)·

**Αλλαγή:** default → DENY· `register-command` ΑΠΑΙΤΕΙ δηλωμένη συνταγματική κλάση
⇒ αταξινόμητη εντολή ανέκφραστη· predicate handler → fail-**closed**· ρητή δήλωση
audience αντί «απουσία token ⇒ δημιουργός».
**Γιατί δεν υπάρχει ανώτερη — ΚΑΙ πού υπάρχει:** reachable ταβάνι = «εντολή χωρίς
κλάση δεν καταχωρείται». **ΥΠΑΡΧΕΙ ανώτερη:** πλήρεις **information-flow /
capability types (DIFC)** όπου «AI στο έμπιστο μονοπάτι» είναι *type error*, όχι
runtime άρνηση — καταγεγραμμένη στο `O4-NORMATIVE-SPEC-v1.0 §4/§8` + Model C του
evidence pack (`NoPrivilegeEscalation`, EXHAUSTED 15.329 states). Προτείνεται η
reachable μορφή ως ρητή επιλογή scope: οι πλήρεις IF-types στη Lisp είναι γνήσια
νέα κατασκευή· η reachable μορφή ήδη σκοτώνει την κλάση στο σύνορο καταχώρησης.
**ΚΡΙΣΙΜΗ διόρθωση ελέγχου:** οι εντολές είναι **~162, όχι 130** (32 μέσω macrolet
`(reg …)` στο `builtin-commands.lisp`). Η αντιστροφή πρέπει να μπει ΜΑΖΙ με κλάση
σε κάθε εντολή· αλλιώς μπλοκάρει **159/162** — «bricking». Άρα Π4 = ενιαία,
αδιαίρετη αλλαγή (default + κλάσεις μαζί), ποτέ σταδιακή.
