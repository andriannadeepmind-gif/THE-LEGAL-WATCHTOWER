# VSC-Ω — The Promulgated Verified Statutory Calculus (K-CAT steelman)

**One sentence.** A Catala-class prioritized-default calculus, mechanized in F* and transported through a CakeML-verified compilation chain, wrapped in a single-writer certificate-carrying institution whose every trusted artifact — statute bytes, formalization, compiled binary, query answer, cost bound, evolution step — is a pure, total, offline-replayable derivation; where the legal order permits it, the calculus text is itself the promulgated operative law (the DGFiP cell), dissolving rather than bounding the formalization gap.

## A. Kernel calculus (DIM-01: prioritized-default-verified-calculus)
- Surface language: literate, statute-isomorphic scopes (Catala-class): each rule is lexically nested under the pinpoint statutory span it implements; defaults + exception trees + explicit priority orders are typed objects.
- Desugars to the default calculus (δ-calc) with an F*-mechanized semantics; proven-sound compilation δ→λ (the ICFP'21 Catala artifact; extended kernel per the "Closing the Loop" line, arXiv 2606.23913). EXECUTING WITNESS exists.
- **Totality by construction**: no general recursion, structural recursion and bounded iteration only; strong normalization of δ-calc is a mechanizable theorem. Conflict-between-exceptions and missing-definition are typed errors, fail-closed (H3) — an undischarged applicable exception can never be silently ignored: exception search is exhaustive over the statically committed exception tree.
- Honest scope: defeasibility is prioritized defaults, NOT an argumentation defeat calculus; even-attack-cycle norm conflicts compile to typed CONFLICT/UNKNOWN, never to a decided answer. The AX-01 semantics gap vs ideal/eager is **recorded, not hidden**.

## B. Verified transport (DIM-06: verified-kernel-chain)
- Backend retarget: λ-calc → CakeML source, with one new mechanized semantics-preservation proof (HOL4) — then CakeML's verified, bootstrapped compiler to machine code. This is exactly the superior transport the frozen AX-21 ceiling names as reachable today.
- The interpreter, the abstract cost meter, and the certificate checker live inside the same verified image. TCB: F*/HOL4 proof-checker kernels + CakeML binary + hardware — enumerated, minimized, hash-committed.
- Third party re-checks: re-run F* and HOL4 proofs offline; recompute-and-compare every build step. (New proofs = WOULD_NEED_BUILD, flagged per-axis.)

## C. Corpus, citation, time (DIM-02/03/04)
- Hash-committed **legal-order profile** as data: citation grammar G, gazette/publisher identity and keys, calendar, language normalization, deontic lexicon. No order-specific logic in the mechanism.
- Admission of source bytes: publisher signature verification where the gazette signs (eIDAS-class), else k-of-n independent capture witnesses and/or TLS-oracle attested capture; below that, typed UNKNOWN/provisional. Merkle-committed corpus; selection by exact committed identifier only (corpus-size independence, H4).
- Every rule's admission record binds it by digest to the pinpoint span of admitted authority bytes → grounding and citation certificates are derivation-provenance lookups, decidable with zero LLM (the AX-05 ceiling's formal-object half, which this class maximizes).
- **Bitemporal statute store**: every rule carries a valid-time interval and knowledge-time of admission; typed amendment events under a declared formal amendment semantics; every query evaluated at a declared (t_legal, t_knowledge) pair and replayable at that pair; anachronistic derivation is a type error.

## D. Formalization admission (DIM-16 — the class's trust masterstroke)
Two sub-cells, explicitly typed and never conflated:
1. **Publisher-authoritative formal law** (DGFiP/CNAF cell): the executable calculus text is what the authority promulgates and runs; the formalization IS the operative law. Formalization-correctness residual on this cell: zero by identity, not by verification.

## E. Institution shell (DIM-05/07/08/10)
- **Single physical writer seat**; every trusted state transition passes one total decidable kernel predicate K(state, transition, cert) BEFORE canonicalization; acceptance ⇒ certificate-carrying commit with seq' = seq+1; every other outcome a recorded signed refusal with zero state change.

## F. Verdict discipline (DIM-12)

# PCK — Precedential Constraint Kernel (K-CBR steelman)

A proof-carrying common-law reasoner in which the ONLY trusted interpretive artifacts are per-span factor ascriptions and recorded outcomes; no authored rulebase exists in the trusted path. Everything below is buildable today with published, decidable theory (Horty 2011/2012 result+reason models; Horty–Bench-Capon 2012; HYPO dimensions per Horty 2019/Rigoni 2018; CATO hierarchies; hierarchical precedential constraint, van Woerkom et al. ## 1. Committed artifacts (all hash-committed under one Merkle root inside the signed release identity)
- **Opinion corpus** (DIM-02/AX-04): capture records of court-opinion bytes — publisher signature where available, else k-of-n capture-witness corroboration; dual digest with deterministic extraction E(bytes)=text; membership by Merkle inclusion, selection only by committed identifier.
- **Legal-order profile** (DIM-15/AX-22): hash-committed data — factor schema (factor id, polarity per issue, HYPO dimensions with committed value orders, CATO hierarchy edges), per-issue Carneades proof standard + burden allocation, court-hierarchy graph with temporal validity, stare-decisis strength tiers, citation grammar G for case citations. The engine contains zero order-specific logic.
- **Case records**: {case-id, court, dates, per issue: factor set where EVERY factor carries a pinpoint span digest into the captured opinion bytes + the signing curator's identity; outcome; optional reason set (Horty reason model as a strictly-stronger optional layer); treatment events (overruled/limited/questioned) as typed bitemporal events}.
- **Ascription acts** (DIM-16): factor ascription is the single interpretive trust surface. Humans ascribe and sign; an LLM may PROPOSE ascriptions only as untrusted candidates outside the trusted path (H1) — nothing enters the constraining computation without a signed admission transition through the kernel predicate. Curator disagreement = typed CONTESTED ascription → the factor enters as UNKNOWN and flows into stability analysis rather than being resolved by fiat.

## 2. Trusted engine (pure total functions of the frozen closure)
- **forcing(q, CB@(t_legal,t_know), profile)**: compute the constraining set (filter by court-hierarchy bindingness, temporal validity, treatment state at the queried bitemporal pair); test a-fortiori dominance Pro_s(Y)⊆Pro_s(X) ∧ Opp_s(X)⊆Opp_s(Y), lifted through the CATO hierarchy (hierarchical constraint) and through dimension value-orders. Output per issue: **FORCED_π / FORCED_δ / OPEN / INCONSISTENT-CB** — the OPEN verdict is a certified legal-content answer ("either outcome is consistent with the committed case base": where binding law ends and discretion begins), distinct from typed UNKNOWN (ignorance).
- **Semantics** (AX-01): FORCED(s) iff s holds in EVERY case-base-consistent decision of X — sceptical quantification, per-query unique, deterministic, decidable O(|CB|·|F|). Certificates in BOTH directions: FORCED carries the dominating precedent + dominance trace; NOT-FORCED carries an explicit consistent counter-decision witness plus an exhaustive-scan record naming, for every binding precedent, the factor that breaks dominance. Defeater search is total over the committed base by construction.
- **consistency(CB)**: pairwise dominance-conflict scan; INCONSISTENT verdicts carry a kernel-checked counterexample pair (DIM-13).
- **stability(q with UNKNOWN ascriptions)** (DIM-12, AX-09 v2 carve-out): by the monotonicity of dominance in factor presence, verdict stability over ALL completions reduces to checking ONE extremal completion (all unknown opponent-side factors present, all unknown own-side factors absent) — polynomial, not 2^u. When stable: KNOWN-with-stability-certificate. Optional flip-set frontier (all minimal unknown-ascription sets that flip the verdict) computed under a committed AX-17 budget; beyond budget → typed UNKNOWN(BUDGET-EXCEEDED), never a guess.
- **Proof standards**: per-issue Carneades evaluation (standard + burden from the profile) over the structured issue graph — decidable, deterministic.
- **Certificates**: canonical encoding at ONE serialization seat (H4); an independent offline checker (small, producer-free) re-verifies subset/dominance comparisons, hierarchy/dimension lifts, scan completeness against the committed Merkle leaves, extremal-completion stability, and bitemporal filters — zero producer trust (H8).

## 3. Substrate
Single-writer append-only hash-chained ledger; one decidable kernel admission predicate evaluated BEFORE canonicalization; all-or-nothing commits (WAL + atomic rename + read-back verify); every commit certificate-carrying and sequence-monotonic; deterministic parallel map over precedents with ordered serial fold; all nondeterminism sources reified in the committed closure; external fetches quarantined outside the trusted path with typed timeout obligations, fail-closed.

## 4. Adversarial + evolution

########## K-NSV DESIGN ##########
# NSV-MAX — the strongest Propose/Verify-Out Neuro-Symbolic Pipeline

**Thesis.** The weak form (R5 A5 RAE) failed because model emissions could *become* premises. NSV-MAX makes that structurally impossible: there are exactly two planes and one gate, and **no byte authored by a statistical producer ever becomes canonical except as the checked payload of a certificate that a deterministic kernel recomputed**. The LLM is an oracle for *where to look*, never for *what is true*. Every mechanism below is buildable today from named components; the three artifacts that are spec-only are enumerated in §12 and tagged WOULD_NEED_BUILD in the axis profile.

## 1. Trust topology
- **Proposer Plane P (untrusted, parallel, replayable):** an ensemble of pinned open-weight LLMs (weights hash-committed; batch-invariant inference kernels per the AX-14 v2 determinization retraction, so every proposal is a pure function of the committed prompt closure within a pinned hardware class; where cross-hardware portability is needed, the candidate bytes themselves are committed — record/replay). Roles: retrieval proposer, autoformalizer, lemma-DAG planner, proof-search policy (test-time proof search), counterexample/attack proposer, verbalizer. Every emission is a `Candidate{bytes, producer-id, model-hash, prompt-closure-hash, sampler-params}` journaled with **zero authority**.
- **Kernel Plane K (trusted, pure):** a small Lean 4 kernel — pure total functions only; IO/clock/RNG are absent from the derivation context *by the type system*, so nondeterminism in the trusted path is a build error. All trusted decisions are functions of the **committed closure** (corpus roots, rulebase, profile, plan, budgets, logical clock).
- **The verify-out gate:** one total, pure, decidable predicate `K(state, transition, certificate)` at one physical single-writer serialization point. Acceptance ⇒ certificate-carrying, `seq' = seq+1` monotonic transition; **every** other outcome — including an error inside the gate's own predicates — is a recorded signed refusal with zero state change. Pre-action independent receipts are written by the gate *before* any effect executes; the acting model cannot touch the trail.

## 2. Admission (corpus and rulebase are different doors)
- **Source bytes (DIM-02):** enforced typed admission acts only; selection strictly by exact committed identifier + Merkle inclusion; similarity retrieval lives wholly in P and re-enters only as a candidate identifier that the gate resolves against the admitted set (corpus-size-independent grounding by construction). Corpus log is append-only, hash-chained, **version-indexed**: every source unit carries `(unit-id, version-interval, span digests)`.
- **Formal rules (DIM-16):** LLM autoformalization is strictly a candidate; admission requires a **signed human-authority record** binding rule ↔ NL pinpoint span, plus the **standing round-trip verbalization invariant**: the admitted rulebase carries a committed verbalization, machine-checked for drift on every rulebase change; drift blocks admission fail-closed. This is the class's honest answer to the interpretive gap: the NL→formal step is never machine-trusted; it is human-signed and machine-*falsified* (see exceed claim on AX-01's negative clause).

## 3. Reasoning substrate — the dominance-conjecture play
The rulebase is **structured defeasible rules with typed exceptions and a committed priority order, whose atoms range over decidable theories** (linear integer arithmetic, dates/deadlines/intervals) — the workloads the v1 conjecture ignored and that K-NSV natively owns via SMT.

Acceptance semantics: **sceptical acceptance under preferred semantics (with the ideal-semantics fast path), computed by certified reduction to the classical solver** — the in-class move that tests the AX-01 dominance conjecture head-on:
1. A **fixed, deterministic, verified encoder** compiles the committed rulebase + query into (a) grounding of theory atoms via proof-producing SMT (cvc5/Alethe, checked by the Carcara checker) and (b) an argumentation-framework SAT encoding (Besnard–Doutré/ASPARTIX lineage).
2. Preferred extensions are **exhaustively enumerated** by SAT with blocking clauses; each "no further extension" step and each maximality (preferredness) check emits an **LRAT proof checked by cake_lpr** — a CakeML end-to-end *verified* checker binary that exists and runs today.
3. The answer certificate = extension set + per-extension maximality refutations + final exhaustiveness refutation + the encoder's input/output digests. Per-query unique, deterministic, decidable on the finite base (H5/H3); **absence-of-defeater is itself certified** (the labelling plus refutations); anything unformalizable, contested, or over budget is **typed UNKNOWN — no proof, no answer**.
4. The encoder-soundness theorem (encoding correct w.r.t. the argumentation semantics) is a finite combinatorial statement targeted at Lean 4; it is the one load-bearing spec-only proof (§12).

Because the *substrate* remains the classical monotonic solver and defeasibility is admitted **data** compiled through a verified transform, this stays inside the DIM-01 family — and if it stands, the AX-01 dominance conjecture is falsified: the classical substrate reaches R5 while *also* covering theory atoms that pure AF calculi lack.

## 4. Pipeline (all model text flows left, all authority flows right)
NL query → (P) formalization candidates → (K) parse/type/admission against committed grammar and rulebase signature → (P) **lemma-DAG plan** → (K) the plan is admitted as a **Lean proof skeleton**: goal = target theorem; nodes = typed lemma obligations; edges = proof-term composition. Goal entailment, gap-freedom, and step soundness are literally kernel-checked; a `sorry` is a typed UNKNOWN obligation, and a defective plan **cannot come into existence** (fail-closed macroexpansion) → (P) budgeted test-time proof search per obligation (AlphaProof pattern: untrusted search, trusted checking) → (K) certificate assembly → (P) verbalization → (K) **round-trip drift check**: the verbalized answer is re-parsed and checked equivalent to the proof object; divergence blocks serving. The served explanation **is** the proof object (or its checked-equivalent verbalization) — divergence between explanation and decision is structurally impossible.

## 5. Certificates — assumption-tiered (the trust-boundary architecture)
Every certificate declares its tier: **T0** Lean-kernel-checked; **T1** checked by a *verified* external checker (cake_lpr LRAT, Carcara-checked Alethe); **T2** solver-attested only. T2 never serves as PASS — it is lifted to T0/T1 or decays to typed UNKNOWN. **Per-claim mechanical binding** (Proof-Carrying Numbers generalized): every atom in a served answer is bound to `(rule-id, source span digest, version-interval, t_legal)`; every citation carries the offline-recheckable tuple (proposition, pinpoint span, authority status at stated legal time via the version index and admitted treatment-graph data). Citation-like strings outside the committed grammar are typed UNKNOWN-CITATION, never upgraded.

## 6. State, time, memory
- **Matter state:** canonical typed record, single seat, writes only through the gate as all-or-nothing journaled transitions; reads deterministic. Reflective records (the system's own performance/evaluation data used by the improvement loop) are typed transitions through the *same* gate — memory about the self is as gated as memory about the world.
- **Bitemporality:** every answer is stamped `(t_legal = version key, t_knowledge = corpus Merkle root at derivation)` and is a pure function of that pair; any prior root is a valid historical t_knowledge; replay at the pair is exact. Cross-claim anachronism (mixed t_legal within one derivation without a typed cross-time rule) is rejected fail-closed.
- **Integrity witnessing is internal-consistency-only by class signature:** append-only chain, checkpoint-relative fork detection — the honest fork-consistency floor, declared, not hidden.

## 7. Orchestration, durability, liveness
Durable execution journal: every step journaled before execution; idempotency-keyed retries; compensations and intent/outcome journaling for external effects, with the irrevocable external act structurally outside the atomic section (matching the AX-11 ABSOLUTE clause). Commit = WAL + fsync barriers + atomic rename + read-back recompute (a transition counts committed only after recompute-and-compare of persisted bytes). Every trusted loop carries a well-founded variant; every solver/proposer call carries a **deterministic budget in abstract inference units** (conflicts, node expansions — never wall clock, preserving replay); terminal type = {SUCCESS+cert, typed FAIL, typed UNKNOWN/REFUSED} with no hang inhabitant; Lean's termination checker makes kernel non-termination a build error.

## 8. Cost and throughput
The kernel meters every run in exact abstract units recomputable to bit-equality; committed per-workload-class budgets are a **fail-closed envelope** — breach is a typed refusal, never silent degradation. Declared complexity classes: certificate *checking* is linear in certificate size; *search* is budget-capped B(class). Throughput: proposers embarrassingly parallel in P; verification is deterministic parallel-map with ordered serial fold through the gate; commits batch-amortized; overload is typed backpressure.

## 9. Falsification
Adversarial proposers (cross model families) generate attacks, mutations, and countermodels; **a refutation counts only when kernel-checked** (Lean/SMT/SAT-certified counterexample) — no LLM adjudicates an LLM. Independence is *machine-checkable*: the committed prompt-closure hash of a critic run proves its context excluded implementer rationale, and its producer-id proves a distinct model family. Findings live in a typed ledger; an unresolved finding blocks release admission fail-closed; escalation is a typed obligation to the accountable human authority.

## 10. Evolution
Verifier-gated improvement: any change — including a proposer-model swap — installs only after the gate recomputes the committed capability-floor vector from the prior release's chained census, proves pointwise non-regression, and re-checks all preservation proofs; statistical learning is confined to P and cannot alter K.

The kernel is a single Lean functor over a hash-committed `LegalOrderProfile` (citation grammar, calendar, deontic lexicon, publisher identities, article ranges). Because the kernel is pure, the *only* channel by which jurisdiction facts reach a trusted decision is the profile parameter — noninterference by construction, stated and proved as a kernel lemma. Generality is calculus-relative (single-calculus-multi-order): an order the calculus cannot express yields typed UNKNOWN, never a guess.

########## K-BFT DESIGN ##########
# QUORUM CUSTODIAN — maximal K-BFT instance (Replicated Deterministic Legal Ledger)

## 0. Thesis
The A4/CFLLD post-mortem proved that an institution that does not hold the bytes cannot replay, cannot detect its own blind spots, and dies with its sources. The single-writer answer ("hold the bytes once, let witnesses watch the custodian") converts that lesson into a new single point of institutional failure: one organization's key, one organization's ops team, one organization's continued existence. K-BFT completes the lesson: **the institution IS a quorum of mutually distrusting custodians, each holding all the bytes, and canonical truth is whatever the one machine-checked-nonforking replicated total order admits.** Every trusted decision is independently recomputed by every operator before it exists; equivocation is prevented by quorum intersection, not detected after the fact.

## 1. Topology and trust model
- Validator set: n = 3f+1 replicas, recommended n = 7 (f = 2), minimum n = 4 (f = 1), operated by institutionally independent categories (e.g., bar association, court administration, national printing office/gazette authority, a university law+CS faculty, a notarial chamber, an archival institution, the creator's organization holding exactly ONE seat). Heterogeneous/asymmetric quorum declarations (FBA/Satrapy-class) are admissible at the membership layer and are themselves committed data.
- Threat model, declared: safety (nonforking, admission integrity) holds against ≤ f Byzantine operators; liveness holds under partial synchrony with ≤ f faulty. **Declared degradation above threshold (honest):** if ≥ f+1 collude, forks become possible — but every committed entry carries a quorum certificate, so any safety violation yields cryptographic, producer-attributable evidence identifying ≥ f+1 signers of conflicting entries (accountable-safety / BFT-forensics results). Above threshold K-BFT degrades exactly to the witness-class evidence regime (attributable fork proofs), never below it. Below threshold it is strictly above it.
- Genesis: validator identities, quorum rule, initial code identity, and the creator's governance key are the hash-committed genesis trust anchor (irreducible per the AX-12 ceiling — signatures transfer trust, they cannot create it). Genesis is published widely and externally timestamped.

## 2. Consensus substrate (DIM-05 bft-replicated-total-order, DIM-09 full-bft-replication)
- One machine-checked-nonforking replicated total order realizing ONE LOGICAL WRITER (the frozen H4/AX-03 wording names this realization explicitly). Concrete, buildable today, two admissible instantiations:
  (a) CometBFT/Tendermint-class: production-grade, TLA+ safety spec model-checked (Apalache), deterministic ABCI state-machine interface; or Mysticeti-class DAG-BFT (production in Sui) for sub-second finality.
  (b) Verified-substrate option: Velisarios-class (Coq-verified PBFT with extracted executable) or the ACL2-verified nonforking DAG-consensus line — machine-checked agreement/nonforking proofs replayable offline today.
- Order-then-execute (Calvin-class): consensus orders opaque transaction bytes; the deterministic execution layer evaluates admission at the committed position. This is deterministic conflict-ordered execution per the v2 AX-03 ceiling — non-commuting effects execute under a pre-committed serialization order.
- External time: every block header is countersigned by k-of-n external time authorities (Roughtime-class + eIDAS-qualified TSA), giving offline-verifiable wall-clock brackets per the AX-17 ceiling clause (c).

## 3. The admission kernel at consensus commit (H4, fail-closed totality)
- One total, pure, decidable predicate K(state, tx, cert) IS the replicated state machine's transition function. A transition becomes canonical iff 2f+1 replicas deterministically compute K = ACCEPT at its committed sequence position — admission strictly BEFORE canonicalization, at the single logical serialization point.
- Every non-acceptance — including an error raised inside K's own predicates — is itself a committed, quorum-certified REFUSAL entry with zero state change (fail-closed totality per the AX-12 ceiling). K's evaluation is wrapped in a total exception boundary whose only non-ACCEPT outcome constructor is the typed refusal.
- **Omission accountability (unique to this class):** a submitter sends the transaction to f+1 validators; inclusion rules (leader rotation / DAG inclusion) guarantee eventual ordering under liveness assumptions, so the institution cannot silently drop a request — a single writer can (no record, no refusal, nothing to audit).

## 4. Trusted legal core (DIM-01, replicated)
- Reasoning substrate: grounded-defeasible-certified labeller (alternating-fixpoint well-founded labelling with offline-recheckable derivation trees) + grounded-defeasible-over-decidable-theories (dates/deadlines/arithmetic via solver-discharged defeater search), with the certified ideal/sceptical-preferred rung (certified exhaustive-extension enumeration, refutation-complete search traces, e.g. proof-logging SAT/ASP enumeration) available under a declared, committed AX-17 cost budget for even-cycle norm conflicts. [The certified-enumeration certifier is spec-only today — flagged WOULD_NEED_BUILD.]

- H1: no statistical model exists anywhere in the state machine. LLM output (candidate formalizations, candidate citations, retrieval suggestions) enters only as untrusted candidate transactions that must pass K, carrying attested human-authority admission records (DIM-16 below).

## 5. Byte custody (DIM-02 — the CFLLD lesson, completed)
