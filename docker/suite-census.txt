#   • αφαίρεση/εξαίρεση σουίτας  ⇒ λείπει από το gated set  ⇒ ΚΟΚΚΙΝΟ
#   • προσθήκη νέας σουίτας      ⇒ επιπλέον στο gated set   ⇒ ΚΟΚΚΙΝΟ
# Και οι δύο κατευθύνσεις απαιτούν ΡΗΤΗ, αναθεωρήσιμη μεταβολή αυτού του
# αρχείου — ίδιο πρότυπο με το gate-registry.sexp (ακριβής set-ισότητα).
