# ούτε έτρεχε, ούτε δηλωνόταν, ούτε καν φαινόταν. Σιωπηλό κενό (ο κριτής C βρήκε 8).

# ΔΟΜΙΚΗ ΛΥΣΗ (totality): ο verify-proof-manifest.py επιβάλλει ΠΛΗΡΗ κάλυψη —
# ΚΑΘΕ tests/*.lisp πρέπει να είναι είτε gated σουίτα (-test.lisp) είτε ΕΔΩ
# δηλωμένο «nonsuite:» με ΛΟΓΟ· οτιδήποτε αταξινόμητο = fail-closed. Έτσι το
# σιωπηλό κενό γίνεται ΔΟΜΙΚΑ αδύνατο, όχι απλώς απαγορευμένο.

# Μορφή: «nonsuite: <filename.lisp>  # λόγος». Τα παρακάτω είναι κληρονομημένα

# η τυχόν αναβίωση/διαγραφή τους είναι απόφαση δημιουργού (εκκρεμεί), αλλά το
# κενό ταξινόμησης κλείνει ΤΩΡΑ.
